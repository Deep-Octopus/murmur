# Murmur

> *Turn loud chat chaos into a calm murmur.*
> **把喧嚣的多软件消息轰炸，降噪成桌角一声克制的低语。**
> 专为同时挂着多家企业飞书、微信、QQ、钉钉、Slack 的 macOS 多屏重度办公者打造。

## 为什么做 Murmur？

当你同时加入三家公司的飞书租户、挂着十几个微信与 QQ 项目群、外接两三块显示器写代码时：
- 来回 `⌘ + Tab` 切软件、切企业租户极其打断心流；
- 市面上的逆向 Hook 工具存在严重的**封号风险**，企业开放平台机器人又需要各家公司管理员审批；
- 许多聚合通知连「消息免打扰」的 99+ 水群也混进来，而花哨的弹窗工具看半小时就会造成强烈的视觉疲劳。

**Murmur 的设计哲学**：
1. **100% 浅层零侵入**：不注入动态库、不逆向协议、不解密聊天数据库、不发任何网络请求。仅通过 macOS 原生无障碍树（`AXUIElement`）与系统通知中心事件监听提取未读信号。
2. **智能识别「消息免打扰」+ `@我` 破圈**：结合客户端静音标识、`[N条]` 免打扰前缀、折叠目录识别与 macOS Dock 真实未读角标上界校验，**自动静默折叠免打扰闲聊群**；但只要免打扰群里出现 **`@我` / `@所有人`**，立即破圈置入待办并打上 `@提及` 标记。
3. **纯时间顺序 + 防久置沉底**：拒绝不可控的黑盒乱序，默认将**等待最久未处理的会话**排在第一行（支持切换最新在前），满 5 分钟暖色微标提醒、满 15 分钟陶土红时钟提醒并温和复醒，保证重要消息绝不漏单。
4. **全天 10 小时零视觉疲劳**：单一圆角锚定表面阻尼展开，支持浅色纸感 / 深色石墨自适应，甚至支持**无待办时完全隐藏桌面胶囊（仅保留菜单栏图标）**，把屏幕完全还给你的代码与文档。

## 核心功能闭环（v1.1）

- **任意 IM 软件动态接入（免重编译）**：内置飞书（含多企业侧栏识别、跨租户会话去重与 `feishu-notifier` 监听）、微信、QQ；支持一键添加 **钉钉、企业微信、Slack、Telegram、Discord、系统邮件**，或直接从 `/Applications` 选择任意桌面应用。
- **五层免打扰降噪引擎**：
  - 自动剥离「消息免打扰 / 折叠的群聊 / 订阅号 / 服务号」及灰色免打扰角标会话，收纳在底部一行极静默抽屉（可随时点开查看，绝不误删）；
  - 群内 `@我` / `@所有人` / `[加急]` 自动破圈提至主列表；
  - 对仍开启通知但不想关注的群聊，支持右键一键加入**永久屏蔽名单**。
- **三通道互补感知**：
  1. **左侧会话列表无障碍扫描**（飞书 / QQ / 钉钉 / Slack 等）：自动激活 `AXManualAccessibility` 读取存量未读会话、条数、摘要及多企业后台角标；
  2. **系统通知中心横幅实时捕获**（微信 4.x 等封闭渲染客户端）：通过 `AXObserver` 毫秒级捕获新消息横幅发送人与正文；
  3. **Dock 角标真值联动**：在原软件读完消息、角标归零后自动同步消隐。
- **精准会话直达 & 顺手人体工学**：
  - 点击会话自动跨企业租户并点开对应聊天窗口（自动收起面板不挡视线；也可点右上角 📌 **固定常驻**）；
  - 点击面板外部自动收起；鼠标左键点顶部菜单栏图标直接展开队列（实时显示待办数），右键呼出快捷控制菜单；
  - 支持按 **`Space` 空格键**原地展开多达 8 行完整长消息预览，无需跳转即可扫完长通知；
  - 支持单条完成、一键「全部标为已阅」及 **`⌘ + Z` 5 秒后悔药撤销**；支持延后 `15m / 1h / 3h / 明早 09:30` 再提醒。

## 快速安装与构建

### 方式一：直接下载预编译包（推荐）

1. 前往 [GitHub Releases](https://github.com/Deep-Octopus/murmur/releases) 下载最新的 `Murmur-v1.1.0-macOS-arm64.zip`，解压后将 `Murmur.app` 拖入 `/Applications`（应用程序）目录；
2. 首次打开若提示未签名应用拦截，执行一次去隔离标记后即可运行：
   ```bash
   xattr -cr /Applications/Murmur.app
   open /Applications/Murmur.app
   ```

### 方式二：源码一键构建

环境要求：**macOS 14.0+**（已兼容 macOS Sequoia / Tahoe / 27），安装 Xcode Command Line Tools 即可极速构建（零第三方依赖）。

```bash
git clone https://github.com/Deep-Octopus/murmur.git
cd murmur
chmod +x scripts/build_app.sh
./scripts/build_app.sh
open /Applications/Murmur.app
```

首次启动后点击面板顶部提示开启 **系统设置 → 隐私与安全性 → 辅助功能 → Murmur** 即可。
> 💡 **自编译权限保活提示**：若本机钥匙串中存在 `Apple Development` 证书，`scripts/build_app.sh` 会自动使用证书签名，后续版本升级无需重复勾选辅助功能权限。

## 快捷键一览

| 快捷键 | 作用 |
| :--- | :--- |
| `⌥ + M`（可切换 `⌥ + Space` / `⌃ + ⌥ + M` / `⌘ + ⇧ + M`） | 全局展开 / 收起待处理队列 |
| `↑` / `↓` | 在待处理会话间上下移动选中项（长列表自动跟随滚动） |
| `Space`（空格） | 展开 / 收起当前选中会话的完整长消息正文（最多 8 行） |
| `⏎ Return` | 跳转到当前选中的会话并自动收起面板（未固定时） |
| `⌫ Delete` | 将当前选中会话标记为已完成 |
| `⌘ + Z` | 撤销刚刚的完成 / 批量已阅 / 屏蔽操作 |
| `S` | 将当前选中会话延后 15 分钟再提醒（右键可选 1h / 3h / 明早 09:30） |
| `Esc` | 收起面板并归还焦点 |
| `按住 ⌥ 拖动` | 在开启「锁定位置」时临时拖动悬浮胶囊 |
